# 数据源说明

## 实际来源流程

用户从官方网页或附件下载文件，再上传到本地网页。项目保存用户选择的来源标识、原始文件快照和标准化记录，不假设官网存在稳定 API。

## 支持的来源类型

- 国家统计局：生产、需求、价格和国家统计局口径的贸易总量。
- 中国人民银行：货币、信用和贷款；官方统计页面或附件优先。
- 国家外汇管理局：结售汇、涉外收付款、外汇储备和国际收支。
- 财政部国库司：财政收支及政府收支/融资数据。
- 中国货币网：中国利率和 FDR007 定盘数据。
- FRED：美国利率、美国国债收益率和美元指数，API Key 只从环境变量读取。
- cnbs：可选的指标搜索、口径确认和最新值核验适配器，不替代来源原始记录，也不是网页上传的必要条件。

项目代码还保留部分官方 Provider 和 FRED 适配器，但它们是可选扩展能力；当前普通用户的主流程仍是“官网下载文件 → 网页导入 → 预览确认”。

## 口径边界

国家统计局贸易数据不标记为海关原始数据；FDR007 不改名为 DR007；缺失值不填充为零。
